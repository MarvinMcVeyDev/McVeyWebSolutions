# McVey Web Solutions — Temporary Landing Page

A responsive, single-file landing page for McVey Web Solutions while the full website is under development.

## Features
- Responsive layout for desktop, tablet, and mobile
- Dark charcoal and electric-blue visual theme
- Service highlights and portfolio call to action
- Accessible link labels and reduced-motion support
- Automatically updated copyright year
- No framework or build step required

## Run locally
Open `index.html` in a modern browser.

## Before publishing
1. Confirm `contact@mcveywebsolutions.com` is an active email address and update it if needed.
2. Replace the LinkedIn placeholder URL with your actual profile.
3. Confirm the portfolio and GitHub links.
4. The decorative mountain photos are loaded from Unsplash, so those images require an internet connection.

## Deployment
Upload `index.html` to the document root of your static hosting provider. Keep the portfolio subdomain's DNS and hosting configuration separate from the main domain.
